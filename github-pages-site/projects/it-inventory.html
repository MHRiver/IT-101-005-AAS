IT Inventory Manager

A command-line application for keeping device names, types, IP addresses, and locations in one database.

PythonMySQLUbuntuVirtualBox

System at a glance

Python CLI→MySQL connector→Ubuntu VM→devices table

What I built

  • Designed a devices table with id, name, device_type, ip_address, and location fields.
  • Built a menu around adding, viewing, updating, and deleting devices. The shared code includes the menu and add-device implementation; final coverage of every action still needs confirmation.
  • Connected the Windows Python client to MySQL in a local Ubuntu VM. Used a forwarded localhost port while troubleshooting VM networking.

Troubleshooting notes

Connection refused

Checked whether MySQL was reachable before debugging the application. A Windows Test-NetConnection check to localhost on TCP 3306 succeeded.

Parameterized SQL

Used %s placeholders and a separate values tuple with mysql.connector, keeping query structure separate from input.

What I learned

  • Database persistence separates stored records from the Python program.
  • A successful port check verifies connectivity, while a query verifies the application/database path.

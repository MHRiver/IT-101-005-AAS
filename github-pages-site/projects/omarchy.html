Omarchy Virtual Machine

A Linux desktop experiment inside VirtualBox on a Windows laptop.

VirtualBoxOmarchyHyprlandLinux

System at a glance

Windows laptop→VirtualBox→Omarchy→Hyprland

What I built

  • Installed Omarchy in a VirtualBox VM on the Lenovo laptop.
  • Worked through a blank desktop with a visible mouse cursor.
  • Reported a working Hyprland desktop after enabling software OpenGL; display scaling was the next adjustment.

Troubleshooting notes

Blank graphical desktop

Kept VMSVGA, 128 MB display memory, and 3D acceleration, then added LIBGL_ALWAYS_SOFTWARE=1 through the Hyprland environment configuration.

Missing editor

The expected nano command was unavailable, requiring another way to edit the configuration.

What I learned

  • A running cursor does not guarantee the desktop renderer initialized successfully.
  • Software rendering can help isolate a virtual GPU compatibility issue.

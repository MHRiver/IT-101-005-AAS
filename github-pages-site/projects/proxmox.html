Proxmox Home Lab

A home server environment for experimenting with virtual machines, containers, and self-hosted services.

ProxmoxDell PowerEdgeLinuxVMs & LXC

System at a glance

Dell PowerEdge R630→Proxmox→VMs & LXC→Self-hosted services

What I built

  • Used a Dell PowerEdge R630 with dual Xeon E5-2680 v4 processors as a lab platform.
  • Created Linux VMs and LXC containers for services including networking, game hosting, and application experiments.
  • Worked with Proxmox 8.4, storage allocation, CPU/RAM assignment, and network reachability. Hardware allocations have changed over time.

Troubleshooting notes

Choosing VM or LXC

Compared the lighter resource footprint of containers with the isolation and full operating system of a VM.

Storage allocation

Investigated the difference between a virtual disk’s capacity and the space available inside a guest filesystem.

What I learned

  • Virtualization lets one server support several independent experiments.
  • Document the guest, host, network, and storage layers separately when troubleshooting.

WireGuard Remote Access

A self-hosted VPN for reaching home services from a phone and remote networks.

WireGuardLinuxiOSUDM Pro

System at a glance

Remote device→WireGuard endpoint→Home network→Private services

What I built

  • Ran WireGuard in the home lab, including Linux container-based setups.
  • Configured an iPhone peer and worked with endpoint, port, and routing settings.
  • Later explored access with the UDM Pro network. Exact current peer and routing configuration is not included here.

Troubleshooting notes

Endpoint reachability

Worked with UDP 51820 and endpoint addressing. A private LAN endpoint only works directly from networks that can reach it.

Testing from outside

Cellular testing helps distinguish actual remote connectivity from a test made on the same home Wi-Fi.

What I learned

  • VPN connectivity depends on both the tunnel handshake and routes to the destination.
  • Keep peer private keys and exported VPN configurations out of documentation.

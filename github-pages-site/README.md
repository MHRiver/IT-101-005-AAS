# Andy Serna — project documentation

Static HTML, CSS, and JavaScript site for https://mhriver.github.io/IT-101-005-AAS/

## Publish

1. Extract this ZIP.
2. Upload its contents directly into the repository root. index.html, style.css, app.js, and the projects folder should sit at the top level, not inside another folder.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Select the branch containing these files (usually main), choose / (root), and save.

If Pages already publishes this repository root, pushing the files updates the site. Uploading index.html will replace any existing homepage.

## Edit

Edit index.html for the overview, about.html for the About page, projects/*.html for individual project pages, style.css for design, and app.js for interactions. projects.json is a reference export and does not dynamically update the pages.

Paths include /IT-101-005-AAS/. Update the links if the repository name changes.

Audio & Video Storage Calculator

A coursework script that calculates uncompressed media storage from recording settings.

PythonNJIT AFSIT101

System at a glance

Sample settings→Python calculation→Byte conversion→Formatted output

What I built

  • Ran audio_storage.py in the NJIT AFS environment for IT101 homework.
  • Produced a table of sample rate, channel type, bit depth, duration, kilobytes, and megabytes.
  • Worked with variables, calculations, formatting, and a text file containing script execution instructions.

Troubleshooting notes

Unit conversions

Connected bits per sample, samples per second, channels, and recording duration to storage size.

Remote execution

Used python3 with the script path on AFS and captured the output for the assignment.

What I learned

  • State whether KB/MB use decimal or binary units.
  • Keep inputs and displayed precision clear so calculations can be checked.

Dedicated Game Servers

A self-hosted environment for running and managing multiplayer game servers.

AMPMinecraftSatisfactoryLinux

System at a glance

Players→Network route→AMP / server process→Game world

What I built

  • Used AMP while working with dedicated servers in the home lab.
  • Experimented with Minecraft variants including Spigot, Fabric, Pixelmon, and Cobblemon.
  • Worked on Satisfactory hosting, required ports, and connectivity. Separate instance versions and final configurations are still to be documented.

Troubleshooting notes

Reachability

Investigated the relationship between application listeners, firewall rules, NAT, and client connections.

Modded environments

Worked with different Minecraft server ecosystems; each instance needs matching game, loader, and mod versions.

What I learned

  • Test a game server on the LAN before diagnosing access from outside.
  • Keep a per-instance record of versions, ports, and world data.
